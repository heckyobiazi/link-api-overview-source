# LINK API Overview

One-page developer introduction site for LINK's FX and stablecoin payment APIs.

## Run locally

1. Install Node.js 20 or newer.
2. Extract this project folder.
3. From the project folder, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
npm run start
```

The page is a frontend concept. It does not call LINK's API. The request shown in the quickstart is illustrative; check LINK's current documentation for credentials, supported markets, and required fields before integrating.
